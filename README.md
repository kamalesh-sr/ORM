EX 02 – Django ORM Web Application

Date: 20-11-2026

AIM

To develop a Django application to manage an online food delivery platform using Object Relational Mapping (ORM).

DESIGN STEPS

STEP 1: Clone the problem from GitHub.

STEP 2: Create a new Django project and app.

STEP 3: Create a FoodItem model using "models.py" with a primary key and five fields.

STEP 4: Register the FoodItem model in "admin.py".

STEP 5: Create migration files using "makemigrations".

STEP 6: Apply migrations using "migrate".

STEP 7: Create a superuser to access the Django admin panel.

STEP 8: Run the Django server and add 10 food records through the admin interface.

PROGRAM

The Django application uses ORM to store and manage food details.

Model Fields:

1. Food Name
2. Restaurant
3. Category
4. Price
5. Availability

Primary Key: ID (automatically generated by Django).

OUTPUT

The Django admin page displays the FoodItem table with 10 food records.

RESULT

Thus, the Django ORM web application for managing an online food delivery platform was successfully created and executed.
